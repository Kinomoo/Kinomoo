## 🌟 代表作品
### 🎮 [NTRP 2.0 Showcase](https://github.com/Kinomoo/ntrp-showcase)  
為 Discord GTA RP 伺服器「Neo Terra RP」打造的專用網站。  

- 🌐 Demo：[neotrp.com](https://neotrp.com)  
- 📂 Showcase Repo：架構圖、程式碼片段、功能截圖  
- 🔒 完整程式碼：因含伺服器內部邏輯，僅於應徵時提供私有存取  

**技術重點：**
- 使用 **Next.js + TypeScript** 開發 SSR 架構  
- 串接 **Discord OAuth API** 進行玩家驗證與規範管理  
- Prisma 管理 **PostgreSQL** 資料庫  
- **Vultr VPS (Ubuntu) + Nginx + PM2** 自行部署  
- UI/UX 客製化，平均每日流量數百次，內容存取率達 **73%**
